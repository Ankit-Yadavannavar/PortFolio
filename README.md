# Ankit Yadavannavar — Portfolio

Personal portfolio site built to showcase my full-stack and AI/NLP projects, skills, and experience as I look for SDE / Full-Stack roles.

---

## About

I'm a Computer Science graduate (Presidency University, 2026) focused on full-stack web development and AI-powered NLP systems. This portfolio highlights two of my main projects — **EcoQuest**, a gamified EdTech platform with multi-tenant RBAC architecture, and an **AI-powered multilingual career chatbot** — along with my skills, internship experience, and achievements.

## Features

- Single-page, fully responsive portfolio — no framework, built with vanilla HTML, CSS, and JS
- Animated architecture diagram visualizing EcoQuest's 4-tier role-based access system
- Project breakdowns with tech stack tags
- Experience timeline and grouped skills overview

## Tech Stack

- HTML5, CSS3 (custom design system, no UI framework)
- Vanilla JavaScript (scroll-based reveal animations)
- Fonts: Space Grotesk, Inter, JetBrains Mono (Google Fonts)

`Python` `GPT-3 API` `NLP`
